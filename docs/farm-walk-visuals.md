# Farm walk-cycle assets — handoff to Claude

## Scope

Generated with the built-in imagegen tool, one separate call per species using its existing sitting sprite as the visual reference. The user asked to leave runtime integration to Claude. This work adds assets and documentation only; no walk-cycle changes were made to farm.html, js/farm.js, js/farm-art.js or css/style.css.

## Ready-to-use sheets

All eight runtime sheets are in `assets/farm/walk/<species>.webp`: snowcat, rabbit, panda, fox, shiba, hedgehog, duckling, penguin.

Each is **2304 × 384**, with **6 equal 384 × 384 square cells in one row**, real alpha transparency, facing right. No two-frame fallbacks were used. Every file is below 150,000 bytes. RGB quality is 75–85 depending on the file; exact compression settings are in `assets/farm/walk/manifest.json`.

Generated source sheets are preserved untouched as `assets/farm/walk/source/<species>.png`. The generator returned 2172 × 724 or 1881 × 836 canvases with six figures; they are **not** ready to use as equal-square-cell CSS sheets. The WebP exports isolate the figures, use one common scale per species, center them within equal cells, and align grounded frames. Rabbit frames 3 and 4 preserve their airborne height instead of snapping their feet down.

## Integration notes

- Keep the existing sitting sprites, adoption grid and roster unchanged.
- Add a `.walk-sprite` alongside `.animal-sprite` inside the actor's `.bob`, which is inside `.flip`.
- Show the sheet only for `.walking` or `.hopping`; idle and the keeper on her rock keep the sitting image.
- Each sheet uses `background-size: 600% 100%` and `aspect-ratio: 1`. Animate X from 0% to 120% with `steps(6)` so the visible positions are 0%, 20%, 40%, 60%, 80%, 100%.
- Suggested durations: snowcat .8s, rabbit .7s, panda 1s, fox .6s, shiba .6s, hedgehog .45s, duckling .8s, penguin 1s.
- Use the existing `.actor.left .flip` mirror for leftward travel.
- Remove the existing whole-image `animal-step` tilt and `animal-hop` jump while the sheet is active.
- **Ground anchor:** the strong-opacity contact baseline in the walk sheets is approximately pixel 353/384 (91.9%). The existing sitting assets land around 300/320 (93.75%), and the actor is anchored with `translate(-50%, -94%)`. Offset the walk visual downward by about **1.8% of the square** when wiring it in, and visually verify the switch. Keep the actor's outer square the same size so changing poses does not change layout. Quadrupeds naturally have a lower, longer body in side profile than in the upright sitting pose; avoid stretching their anatomy to match sitting height.
- For `prefers-reduced-motion` and `Sky.calm`, disable frame animation and show frame 0.
- Preload/decode all eight sheets after load/idle, keeping the sitting image visible until the corresponding sheet is ready so a first step cannot flash blank.
