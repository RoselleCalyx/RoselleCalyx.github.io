# 主人工作台

首页的 **Host login** 和 Message 页的主人收信入口都进入同一个 `inbox.html`。沿用收件箱的主人邮箱和密码，不需要第二个账号。首次发布工作台时需部署最新 Worker，并应用 `0002_shared_farm.sql` 和 `0003_owner_content.sql`；现有来信和登录账号保留。

## 使用

登录后可切换以下功能：

- **Site & links**：姓名、角色、单位、地点、公开联系邮箱、Scholar / LinkedIn / GitHub / CV、各页标题和介绍、页脚、星图观测位置。
- **Home**：首页标题、简介、头像、个人介绍、研究兴趣、教育经历、新闻及 Explore 卡片的文字和链接。
- **Papers**：新增、编辑、删除和调整论文顺序；填写类型、作者、年份、会议或期刊、摘要、主题、精选状态、封面图、多张附图及说明、PDF / Code / Project / Data、BibTeX。作者和主题每行一项；BibTeX 留空时自动生成。
- **Gallery**：管理相册、地点、日期、地图坐标、故事、分类、收藏和照片。照片留空可用现有绘画占位图。
- **More content**：公开漂流瓶和公开回复、农场主人和原有居民、Voyager 各站故事及场景。Voyager 至少保留一个站点，每站两行标题；场景图片不能为空。
- **Letters & requests**：读信、标为已读、设置待处理／已处理／归档、写私密处理备注；审核领养申请，查看已批准或拒绝的申请、移除批准的居民、移除共享果树。

内容修改后点击 **Save & publish**。只有云端数据库确认保存才会显示 Published；所有访客下次打开或刷新页面会读取新内容，无需再改源码或推送 GitHub。

### 图片和文件

头像、论文封面和附图、相册照片、Voyager 场景图都可在图片字段旁点击 **Upload & crop** 选择本地图片。头像默认 3:4，论文封面默认 4:3；完整论文图、相册和场景默认保留原比例。可选择方形、横图、宽屏或自定义比例，拖动取景并使用缩放和位置滑块；预览与上传使用同一裁剪区域，不会拉伸照片。

点击 **Upload cropped image** 后，图片地址进入当前草稿；再点击 **Save & publish** 更新网站上的展示。取消或上传失败不替换原图片。上传图片会获得可公开访问的地址；工作台不上传原始文件名，裁剪导出和服务端规范化移除图片元数据。源图片最多 20 MB、32 百万像素，上传结果自动压缩或缩小到最长边 2048 像素、最多 1 MB；支持 JPEG、PNG、WebP，以及浏览器可解码的 AVIF/GIF（动画取首帧）。

图片、CV 和 PDF 仍可填写完整 HTTPS 地址，或已有站内文件路径，例如 `assets/paper1.png`。CV 和 PDF 使用文件地址；留空的公开链接会隐藏。图片库复用现有 D1，最多 100 MB 或 1000 张，每天最多新增 100 张；同一裁剪文件重复上传复用地址，不重复计容量。

上传需应用 `0005_owner_media.sql` 并部署对应 Worker。公开图片通过 `/api/media/{UUID}` 读取；`POST /api/host/media` 仅允许已登录主人从本站上传。

### 草稿和备份

- 切换工作台标签不会丢失未发布的修改，保存失败也保留草稿。
- 离开页面前会提示未保存的内容；退出登录会清空工作台。
- **Export backup** 导出当前公开内容或草稿；**Import backup** 仅导入为未发布草稿，检查后再保存。
- **Reload published** 重新加载云端内容，会提示是否放弃未保存修改。
- 两个窗口同时编辑时，旧版本会被拒绝保存以避免覆盖。先导出草稿，再重新加载最新版并合并。

## 数据和隐私

公开内容存放于 Cloudflare D1 的 `site_content` 单行版本记录。公开 `/api/site-content` 仅返回展示内容；写入 `/api/host/site-content` 必须使用有效主人会话。服务器验证数据结构、大小、图片和链接协议，并在事务中限制农场原有居民加批准居民最多 24 位（主人另计），果园共用 8 个位置。

登录账号、主人密码和会话令牌不属于可发布内容。工作台的公开联系邮箱与登录邮箱是两个字段；修改公开邮箱不会修改主人登录账号。

私信、联系方式、处理状态和私密备注只在主人接口返回。私信不会自动变成公开漂流瓶。领养申请批准前保持私密；移除已批准居民后仍保留申请处理记录。

各公开页面启动时读取同一云端快照，再按原顺序启动页面脚本。如果云端不可用，会在 2.5 秒后显示仓库中的默认内容，避免网页一直空白。工作台不会把网络错误当成成功发布。

详细部署步骤参见 [Cloudflare 配置](message-cloudflare-setup.md) 和 [Worker README](../services/message-worker/README.md)。
