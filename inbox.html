Cloudflare D1 stores private letters. Telegram can notify you even when this page is closed.

  1. Create a Cloudflare account and deploy the message service and D1 database using the guide.
  2. Set the host email, password, Telegram bot, and recipient chat ID on the server.
  3. Add the service’s HTTPS base URL to messageApi in js/config.js.
Cloudflare + Telegram setup guide
  1. Create a Supabase project and run the inbox SQL.
  2. Create a host account and add its UUID to message_hosts.
  3. Add the project URL and publishable key (or legacy anon key) to js/config.js.
