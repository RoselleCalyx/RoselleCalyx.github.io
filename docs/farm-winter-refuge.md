# Crocodile winter refuge

Made with the built-in imagegen tool, following the transparent watercolor/gouache scenery workflow in farm-visuals.md. The untouched generated source is preserved in `assets/farm/scenery/source/winter-refuge-v1.png`. Export with `scripts/export-farm-refuge.cjs`; the runtime image is `assets/farm/scenery/winter-refuge-v1.webp`, 720 px wide, quality 88, alpha quality 100. The export trims empty margins and removes only alpha noise below 8/255 while preserving painted soft edges.

The refuge is provided by the farm caretaker: natural stone, snow on the roof, a sheltered warmed stone floor, no exposed flames. True crocodiles are cold-sensitive. Winter inactivity and reduced feeding are inspired by [Perth Zoo's saltwater crocodile care](https://perthzoo.wa.gov.au/article/perth-zoo-croc-devours-summer); the heated shore refuge is an illustrated farm adaptation, not a claim that wild crocodiles naturally tolerate frozen alpine ponds. Spring restores swimming.
