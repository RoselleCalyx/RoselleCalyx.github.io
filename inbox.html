连接收信服务

尚未连接收信服务。当前页面不会假装收到或保存来信。

使用 Cloudflare D1 保存私信，Telegram 在你关闭网页后继续提醒新信。

  1. 创建 Cloudflare 账号，按说明部署收信服务和 D1 数据库。
  2. 在服务端设置主人登录邮箱、密码，以及 Telegram bot 和接收人的私聊 ID。
  3. 将服务的 HTTPS 根地址填入 js/config.js 的 messageApi。
查看 Cloudflare + Telegram 配置说明
